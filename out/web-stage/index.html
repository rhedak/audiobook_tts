Audiobook TTS Builder

Upload Markdown chapter files, configure voices and pronunciations, and build multi-chapter audiobooks using Microsoft Neural TTS voices. Everything runs in your browser. Microsoft rejects speech requests from web pages, so requests are forwarded through a relay: by default a small hosted one (your chapter text passes through it on the way to Microsoft), or your own local relay if you prefer your text to stay on your machine — see Speech relay below.

    Speech relay

    Microsoft rejects speech requests from web pages, so they must be forwarded through a small relay. By default this page uses a hosted relay: your chapter text passes through the author's server on its way to Microsoft. If you prefer your text to stay on your machine, run your own relay and point this setting at it.
